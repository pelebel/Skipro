# SkiPro — Bug Fixes Plan

## Summary

Fix 3 confirmed bugs and 3 algorithmic issues from the QA report. All changes are in `script.js` and `index.html`.

---

## P0 — Critical Bugs

### 1. Stale error message persists across searches

**File:** `script.js` line ~295

**Problem:** After a failed search shows an error, a subsequent successful search displays weather data but leaves the error message visible. The success path never hides `errorMsg`.

**Fix:** Add `document.getElementById('errorMsg').style.display = 'none';` at the top of the success block inside `fetchWeatherByCoords()`, right after `try {`.

### 2. Spring score inflation — "Epic" for snowless 23°C days

**File:** `script.js` lines 208-235

**Problem:** The spring scoring path can reach 95+ points with zero snow, producing "Epic / 100" for days with no ski-relevant conditions. This undermines the app's core value.

**Fix:**
- Cap `springScore` base at 25 (was 40)
- Add a hard cap: `springScore = Math.min(springScore, 70)` before the final max
- Require at least trace snow (`snow > 0 || prevSnow > 0`) for any score above 50 in spring mode — if no snow exists at all, cap spring score at 30

### 3. Live score uses degenerate mock data

**File:** `script.js` lines 306-313

**Problem:** The live score creates a mock daily object with `snowfall: [0]` and `maxT = minT = currentTemp`, so it never reflects actual daily snowfall.

**Fix:** Replace the mock object with the real daily data at index 0:
```js
const liveResult = calculateProScore(data.daily, 0, hourlyDataForToday);
```
Where `hourlyDataForToday` is the first 24 hours of hourly data (same pattern used for the forecast loop).

---

## P1 — Medium Severity

### 4. Prime badge appears on rainy/cloudy days

**File:** `script.js` lines 401-406 in `renderCard()`

**Problem:** Prime badge is based on hourly data (clear morning hours) while the daily icon reflects overall conditions (rain). This sends contradictory signals.

**Fix:** In `renderCard()`, only render the Prime badge if the daily `weatherCode` is also clear (0 or 1). Add a guard: `if (result.isPrime && weatherCode !== null && weatherCode <= 1)`.

### 5. Deprecated meta tag

**File:** `index.html` line 9

**Problem:** `<meta name="apple-mobile-web-app-capable">` is deprecated.

**Fix:** Add `<meta name="mobile-web-app-capable" content="yes">` on line 10, keeping the Apple variant for backward compatibility.

### 6. Missing focus-visible styles

**File:** `style.css`

**Problem:** Keyboard users see no custom focus indicator.

**Fix:** Add focus-visible rules for `input`, `button`, and interactive elements using a solid outline matching the accent color:
```css
:focus-visible {
    outline: 2px solid var(--accent);
    outline-offset: 2px;
}
```
